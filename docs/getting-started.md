# Getting started

You can be in a server in about a minute.

GameSeek is free, runs in the browser and on Windows, and is built for a squad: chat, voice, and screen sharing. Open [gameseekapp.com](https://gameseekapp.com) and follow the four steps below.

Early access is open. Chat, voice, and servers work today. Parts of the interface are still German while the English localization is in progress. You do not need to wait for that.

## 1. Open GameSeek

| Platform | Link |
| --- | --- |
| Web | [gameseekapp.com](https://gameseekapp.com) |
| Windows | [gameseekapp.com](https://gameseekapp.com) |

The website and the product are served from **gameseekapp.com**. Technical docs also mention **gameseekapp.xyz**, which is the host used by the realtime backend.

## 2. Create an account

1. Register with your email address.
2. Enter the 6-digit verification code sent to that address.
3. Sign in. Login uses the same style of email code.

You can then set a display name, username, profile picture, bio, and status (online, idle, do not disturb, or offline) from your profile.

## 3. Join or create a server

A server is your community space. It holds text channels, voice channels, roles, and members.

- **Join** with an invite code from someone who already has a server.
- **Create** a server, give it a name and icon, then pick a template: Gaming, Friends, Creative, or School.

Server owners can manage channels, roles, members, security, and a danger zone (delete the server or transfer ownership) from server settings.

## 4. Talk to people

| You want to… | Use |
| --- | --- |
| Send a message | A text channel. Right-click a message to edit or delete it. |
| Talk live | A voice channel. Mute, share your screen, or leave from the voice panel. |
| Add someone | Friends. Search by username, then send a friend request. |
| Moderate | Member tools. Ban and kick can include a reason. |

## What to expect right now

You are early, which is the point. A small team ships GameSeek, and a lot of it is still one developer. Your feedback changes the order of the [roadmap](roadmap.md). The [changelog](../CHANGELOG.md) is what already landed.

When something feels off, tell us. That is how the next version gets better.

## Get help

Use the [support form](https://gameseekapp.com/support/index.html). Please do not open a GitHub issue for a bug. Support tickets receive an ID in the form `GS-XXXXXXXX`.

You can also email support@gameseekapp.com.

Read the [community rules](../CODE_OF_CONDUCT.md) before you post in a server.
