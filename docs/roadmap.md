# Roadmap

This is the latest published plan. Dates move when capacity or feedback changes. GameSeek is built by a very small team, so the order below is a focus list, not a promise.

Suggestions are welcome through the [support form](https://gameseekapp.com/support/index.html).

## Done

- Core platform for the website and the app
- First community features
- Basic user accounts
- Server discovery, voice, moderation tools, and the redesigned interface shipped in April 2026
- Profile pictures and further server tools shipped in May 2026

The release notes are in the [changelog](../CHANGELOG.md).

## In progress

**App**

- English localization. The interface is still largely German.

**Website**

- API integration between the backend and the site
- Login and account management on the website

## Next

A release that includes the in-progress work was planned for **16 May 2026**. Treat that date as the plan recorded here, not as a current ship date.

After that, the published feature list is:

- Matchmaking, so players can find a group from inside the app
- Custom invite links for servers and communities

## Later

- Richer profiles
- In-app notifications
- More community tools
- Speed work across the website and the app
- Mobile apps for iOS and Android
- Video calls
- Custom bots and integrations
- A broader friend system
- Direct messages

Friends are already in the app. Direct messages, mobile, video calls, and bots are still ahead.
