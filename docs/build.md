# How GameSeek is built

One developer maintains the website, the app, and the community presence.

## Website

The website is a small stack, built to load quickly.

| Layer | Technology |
| --- | --- |
| Frontend | HTML, CSS, JavaScript |
| Backend | Python |

## App

The app is a component-based client shared by the browser and the Windows build.

| Layer | Technology |
| --- | --- |
| Frontend | React and TypeScript |
| Styling | HTML, CSS, JavaScript |
| Backend | Python |

The same person covers design, implementation, testing, social content, and planning across both surfaces. There is no sprint calendar and no standup. Work happens every day, one change at a time.

For how the pieces connect at runtime, see [Architecture](architecture.md). For how a production host is configured, see [Deployment](deployment.md).
