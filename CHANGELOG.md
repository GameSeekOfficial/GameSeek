# Changelog

All notable updates to GameSeek are listed here, newest first. The format follows [Keep a Changelog](https://keepachangelog.com/).

How to add an entry: [changelog guide](docs/changelog-guide.md).

## 2026-05-02

Published from the 19 April baseline, with profile and server work called out on their own.

### Added

- Profile pictures, including upload, sync, and display
- Further server functions

### Fixed

- Profile images failing to upload, sync, or display

### Changed

- Server system refactored
- Channel categories improved

## 2026-04-19

### Fixed

- General stability. Most known bugs from the April release were addressed.

### Changed

- Overall app performance

## 2026-04-11

The same set of notes was first published on 9 April 2026 and republished, with the same scope, on 11 April 2026.

### Added

- Server discovery through a public server list
- Voice channels, with a reworked audio pipeline
- Ban and kick inside a server
- A redesigned interface across the app

### Fixed

- Member list display
- Logout from Settings, Account, Session
- Server panel channel categories, so voice channels, text channels, and categories can be created again
- Roles and permission assignment
- Ban and kick with a reason
- Account switching, rebuilt for stability

### Changed

- Voice and stream quality: better codec handling and lower latency
- Interface icons, from emoji to SVG
