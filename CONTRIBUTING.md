# Contributing to GameSeek

Thanks for wanting to help. Please read this page before you change anything or send a report.

The project standards below are for people working on GameSeek. This repository is the public documentation. Product bugs still go through support, not through GitHub Issues.

## Report a bug

Do not open a GitHub issue for a bug.

Use the support form:

[gameseekapp.com/support](https://gameseekapp.com/support/index.html)

Every report is reviewed. You will get a ticket ID in the form `GS-XXXXXXXX`.

Security reports have their own path. See [SECURITY.md](SECURITY.md).

## Working on the project

### Keep a backup

Before you edit, save a restore point of the current state. Do not change the only copy you have.

### Write down the change

Record what you changed and why. A meaningful change needs a note. Use the [changelog guide](docs/changelog-guide.md) when the change is user-visible.

### Leave the tree clean

- Match the style already in the code
- Write code the next person can read
- Remove unused code, comments, and files before you hand the work over

### Test first

Run the change before you submit it. Do not hand over work you have not tried.

### Ask before a large change

If you are unsure, ask, then edit. Check with the team before you reshape a major part of the project.

## Questions

Use the [support form](https://gameseekapp.com/support/index.html), or write to the team from the contacts in the [legal notice](docs/legal/impressum.md).

Volunteer roles are listed on the [team page](docs/team.md).
